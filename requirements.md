# Package Requirements

## Project Setup
To run this project locally, install the dependencies listed below.

## Required Packages
### Production dependencies
- react
- react-dom
- lucide-react
- framer-motion
- @supabase/supabase-js

### Development dependencies
- vite
- @vitejs/plugin-react
- typescript
- tailwindcss
- @tailwindcss/vite
- @types/react
- @types/react-dom
- @types/node
- oxfmt

## Install Commands
Run the following in the project root:

```bash
npm install
```

## Recommended Environment
- Node.js 20+
- npm

## Quick Start
```bash
npm run dev
```

This will start the Vite development server for the app.
